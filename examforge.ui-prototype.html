給定一個遞增的整數陣列 arr 與目標值 target，實作 binarySearch(arr, target)：若找到目標，回傳該元素的下標；找不到則回傳 -1。要求時間複雜度 O(log n)。

輸入：arr = [3, 5, 7]，target = 5
輸出：1（arr[1] === 5）
main.js 第 4、7 行有邊界問題
1function binarySearch(arr, target) {
2 let l = 0;
3 let r = arr.length - 1;
4 while (l < r) { // 邊界 1：l === r 時直接跳出
5 const mid = (l + r) / 2 | 0;
6 if (arr[mid] < target) l = mid + 1;
7 else if (arr[mid] > target) r = mid - 1; // off-by-one
8 else return mid;
9 }
10 return -1;
11}

TC5：arr = [10, 20, 30]、target = 10，期望回傳 0，實際回傳 -1。

錯誤分析

錯誤類型
off-by-one（邊界偏移一格），集中在邊界收縮與迴圈結束條件。
出錯機制
第 4 行 while (l < r) 讓「只剩一個元素」時直接跳出、不再檢查；第 7 行 r = mid - 1 收縮右邊界時也跳過 mid 本身。

提示（不給答案）：檢查第 4 行的迴圈結束條件，以及第 7 行——當 arr[mid] > target 時，mid 本身是否仍可能是答案？
